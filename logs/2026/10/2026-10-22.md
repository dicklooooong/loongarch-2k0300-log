| 1 | 采集工具拍出来的图应该正常 | 打开一看**全黑**，测出亮度 3.7/255 | ① 我把曝光写死成手动 300，严重欠曝；② 改成自动曝光后**仍然黑**——自动曝光要几十帧才收敛，我一上电就存图，存到的全是爬坡前的黑帧。加 30 帧预热后才正常（亮度 133） |
| 2 | 保存的图片应该是干净的卡牌 | 每张左上角都有绿色 `SHOT 1/3` | 我把提示文字画在保存用的同一个 `frame` 上。改成**先保存、后画字**（画字只影响回传预览） |
| 3 | 训练日志里 val_acc 95%，应该很不错 | 实拍验证只有 **66.7%** | **数据泄漏**：训练脚本随机划分，同一组连拍的三张图被分到训练集和验证集两边。改成按"组"划分后，才是真实水平 |
| 4 | 小类分得细，应该更准 | 六分类 80% < 三分类 88.3%；九分类 50% < 三分类 73.3% | 每类样本太少（40~45 张），细分把数据砍散，比"监督信号更细"的收益大得多 |
| 5 | 每张 30 张采集量应该够 | 手电筒/望远镜/警棍/装甲车全错 | 每种卡 30 张 = **10 个姿态**（10 组连拍），模型记的是"这 10 张图"而不是"这种卡长什么样" |
| 6 | 模型错的时候应该不太自信 | 手电筒 6/6 全被认成 weapon，置信度 **0.77** | 系统性错误可以很自信；但整体上"错的平均置信度 0.538 < 对的 0.706"，置信度仍可用来筛出可疑结果 |

## 五、关键收获（3 条）

1. **收获**：**验证集划分方式决定你看到的数字是真是假**。同一姿态的连拍图如果分散到训练/验证集，val_acc 会虚高 20~30 个点。按"组"划分后才看到 66.7% 的真相。｜为什么重要：所有"模型效果不好"的判断都建立在准确率上，数字假了，后面全错。
2. **收获**：**数据量决定能分多细**。每类 40 张时，三分类（88%/73%）明显优于六分类（80%）、九分类（50%）。想让层次分类发挥作用，每类至少要 150 张以上。｜为什么重要：这是两次独立实验得到的一致结论，可以当成选型规则用。
3. **收获**：**采集工具必须给人反馈**。没有预览时，卡牌摆没摆正、糊不糊、光线够不够全靠猜；加了画面回传 + 亮度提示后，采集质量立刻可控（亮度 120~141、无偏暗无模糊）。｜为什么重要：数据质量是上限，而数据质量靠工具保证。

## 六、使用方法（写给明天忘了的自己）

### ① 采集卡牌（板子 + 电脑配合）

```bash
# 电脑：先双击 cam-viewer\启动接收端.cmd
# 板子：
cd /home/root
./ncnn_cls shots flashlight 3 250 stream
```

命令结构：

```
./ncnn_cls  shots  <卡种英文名>  <每组张数>  <间隔毫秒>  stream
```

操作节奏：**摆好卡牌 → 看电脑屏幕确认占画面 60~90% → 按回车 → 三连拍 → 换角度 → 再回车**。
输入 `q` 回车退出。

### ② 卡种英文名对照

| 英文 | 中文 | 大类 |
| --- | --- | --- |
| `flashlight` | 手电筒 | 物资 |
| `vest` | 防弹衣 | 物资 |
| `binocular` | 望远镜 | 物资 |
| `pistol` | 手枪 | 武器 |
| `rifle` | 步枪 | 武器 |
| `grenade` | 手榴弹 | 武器 |
| `baton` | 警棍 | 武器 |
| `ambulance` | 消防车（命名有误） | 载具 |
| `armored` | 装甲车 | 载具 |

### ③ 照片同步到电脑

双击 `cam-viewer\同步照片.cmd`，输密码 `1`，照片进
`D:\走马观碑\分类模型训练教程\走马观碑数据集（大改）\我的实拍\<卡种>\`

### ④ 训练

```powershell
cd E:\deepseek\第一个工作区\ncnn_cls\trainer

python train_tiny_classifier.py --data-root "...\dataset_real\train" --img-size 96 --batch-size 64 --epochs 200 --lr 1e-3 --width-mult 1.0 --target-acc 0.99 --patience 40 --num-workers 0 --out-dir "...\artifacts_v9"
```

⚠️ 长命令用反引号续行容易出错，**建议整行粘贴**。

### ⑤ 转 ncnn + 部署

```powershell
pnnx-20260112-windows\pnnx.exe artifacts_v9\tiny_classifier_fp32.onnx "inputshape=[1,3,96,96]" "fp16=0"
```

生成 `.ncnn.param` / `.ncnn.bin`，scp 到板子改名为 `v9.param` / `v9.bin`。

### ⑥ 板子上跑

```bash
./ncnn_cls v9.param v9.bin labels.txt          # 摄像头
./ncnn_cls v9.param v9.bin labels.txt stream   # 摄像头 + 画面回传
./ncnn_cls v9.param v9.bin labels.txt 图.jpg   # 单张图
```
